## ini adalah ide projek saya
> Nama Web: EcoStreak
> Definisi: Game web sederhana untuk menumbuhkan streak lewat kebiasaan ramah lingkungan setiap hari.
> Bahan bahan project
- HTML5: Kerangka struktur web semantik.
 - Tailwind CSS (via CDN): Framework CSS modern untuk tata letak (layout), warna, dan efek bayangan tanpa perlu konfigurasi npm.
- Google Fonts: Menggunakan font Plus Jakarta Sans (font clean dan profesional).
-  Vanilla JavaScript: Logika interaksi untuk centang misi, penghitungan angka, dan simulasi penambahan hari.
- Browser LocalStorage: Menyimpan data streak dan total emisi langsung di browser pengguna (tanpa perlu sewa database atau server).
